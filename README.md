# Entire POC

A proof of concept repository for testing [Entire](https://entire.io) — a developer platform that captures AI agent sessions in Git.

## Overview

This repo demonstrates how Entire tracks AI-assisted code changes, attributing commits to agents and humans alike.

## Getting Started

1. Install Entire CLI
2. Enable in your repo: `entire enable`
3. Start coding with your AI agent
